ねこのきまぐれピアノ

プライバシーポリシー

最終更新日: 2026年10月31日

対象

本ポリシーは、YouTubeチャンネル「ねこのきまぐれピアノ」の運営者が、自身のチャンネルへ動画を自動投稿するために使用するアプリケーション(以下「本アプリ」)に適用されます。

取得する情報

本アプリは、運営者本人のGoogleアカウントに対してのみ、Google OAuthを通じて次の権限を使用します。

  • YouTubeへの動画のアップロード(youtube.upload)
  • 投稿先チャンネルの確認のための、チャンネル情報の読み取り(youtube.readonly)

本アプリは、運営者以外の第三者の個人情報やGoogleアカウントのデータを取得・保存・利用しません。

情報の利用目的と保存

認証情報(リフレッシュトークン)は、運営者が管理する環境に暗号化して保存し、動画の投稿以外の目的には使用しません。取得した情報を第三者に提供、販売、共有することはありません。

Google API サービスのユーザーデータに関するポリシー

本アプリによるGoogle APIから受け取った情報の使用は、Google API サービスのユーザーデータに関するポリシー(限定的使用の要件を含む)に準拠します。

権限の取り消し

本アプリに付与した権限は、Googleアカウントの「サードパーティによるアクセス」からいつでも取り消せます。

お問い合わせ

本ポリシーに関するお問い合わせは、YouTubeチャンネル「ねこのきまぐれピアノ」の概要欄に記載の連絡先までお願いします。
